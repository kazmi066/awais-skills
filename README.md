# Skills

A repo of skills I use with coding agents. Each file is the instructions for one job. I add a file when I want that job done the same way again.

## Creative GSAP landing page

`landing-page-skill.md` builds a landing page from the project you give it. The page is vanilla HTML, Tailwind CSS, and GSAP. Each run works out its own concept from that project.

Paste the file into a chat, or save it as `SKILL.md` where your agent loads skills.
